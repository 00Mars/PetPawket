# Pawket Admin Sample Vault Limitations

Status: explicit limitations for the fake local harness.

The sample vault is not:

- A production vault.
- A real accounting ledger.
- A real source-document store.
- An encrypted blob vault.
- A connector sync endpoint.
- A report package generator.
- An official balance preview.
- An IRS, accountant, investor, foundation, or public impact report.
- A packaged desktop app.

It only proves that a local fake vault can be read by the existing operator preview runner and displayed as a read-only non-production CLI preview.

Production encryption, raw document storage, live ledger commits, official balances, official reports, final exports, public impact claims, connector networking, and packaged desktop UI remain blocked pending review.
