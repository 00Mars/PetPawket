# Pawket Admin Desktop Shell Packaging Blockers

Status: packaging blocked.

The desktop shell must not become a packaged app until these blockers are resolved:

- production encryption not reviewed
- raw document storage not reviewed
- live ledger commits disabled
- official balance/report generation disabled
- final export generation disabled
- connector networking disabled
- privacy/redaction review required
- legal/accounting/tax/security/privacy review required
- UI security review required
- local vault hardening required

Packaging work also requires a decision about desktop framework, signing, updates, secure storage, recovery keys, backups, logging, and admin authentication. Those decisions are not made in this scaffold phase.
